# SPEC.md — Alchemy Forge Frontend

## 1. Цель
Клиентское веб-приложение на React + Vite + TypeScript (или JS), работающее исключительно с REST API бэкенда (VITE_API_URL). Никаких вызовов сторонних LLM API из кода приложения.

## 2. Основные экраны и элементы
- Шапка: название "Alchemy Forge", счётчик прогресса ("Открыто X из Y"), кнопка сброса прогресса (POST /api/reset), статус подключения к серверу.
- Панель доступных материалов: карточки материалов (название, тир/бейдж), фильтрация по тиру и поиск по названию. Клик по карточке кладёт материал в свободный слот крафта (либо drag-and-drop).
- Зона крафта: 2 слота для ингредиентов, кнопка очистки слотов, кнопка "Смешать" (POST /api/craft).
- Блок результата: анимация/подсветка при открытии нового материала, пометка "НОВЫЙ!" если isNewDiscovery === true, или понятное сообщение при неудачной комбинации.
- История / журнал открытий: список найденных в текущей сессии материалов и комбинаций.

## 3. Состояние и сессия
- Генерировать sessionId (UUID) при первом визите и хранить в localStorage.
- Обрабатывать состояния загрузки (isLoading), пустые списки и ошибки сети (включая долгий первый ответ при холодном старте бесплатного бэкенда).

## 4. Ограничения
- Не хранить рецепты и логику крафта на фронтенде — источником правды является бэкенд.
- Не тянуть тяжёлые UI-библиотеки без необходимости; держать код модульным и лаконичным.
