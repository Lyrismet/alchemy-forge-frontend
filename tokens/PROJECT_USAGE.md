# Расход токенов по всему проекту

Источник: страница Usage проекта на claude.ai (Project settings → Usage), снимок 2026-11-26. Скриншот: [project-usage.png](project-usage.png).

Проект вели три сессии Claude Code: координатор и две ветки, по одной на репозиторий.

## Итого: 12,6M токенов

| Input | Output | Cache write | Cache read |
|---|---|---|---|
| 237 | 84,8K | 417K | 12,1M |

## По веткам

| Ветка | Токены | Доля |
|---|---|---|
| Создать фронтенд Alchemy Forge | 6,1M | 49% |
| Создать бэкенд Alchemy Forge | 4,1M | 32% |
| Координатор | 2,4M | 19% |

Примечание со страницы: в итоги не входят проверки разрешений auto mode и ходы, которые ещё выполнялись в момент снимка.

Почти весь объём (≈96%) составляет cache read, то есть повторное чтение уже закэшированного контекста, которое тарифицируется примерно в 10 раз дешевле обычного input. Новых токенов (input + output + cache write) около 0,5M.

Подробный лог по запросам фронтенд-ветки: [TOKEN_LOG.md](TOKEN_LOG.md). Он собран скриптом из транскрипта сессии в другой момент, поэтому его итог может не совпадать со снимком выше.
