# CLAUDE.md

## Режим работы
- Работай строго по SPEC.md и текущей задаче. Не придумывай фичи, которых нет в спеке.
- Перед большими правками кратко напиши план в 3-5 строках и дождись подтверждения (если задача не тривиальна).
- Не выводи целиком неизменённые файлы и длинные объяснения — показывай только нужные diff/фрагменты и краткий итог.
- Не читай подряд все файлы проекта без необходимости; запрашивай или открывай только те файлы, которые касаются текущего шага.
- Всегда держи код простым, читаемым и готовым к деплою на бесплатных инстансах.

## Стек и фокус
- Фронтенд: React + Vite + TypeScript, обращается к бэкенду через VITE_API_URL.
- Опирайся на дизайн-концепт из чата/заметок, но не усложняй верстку лишними зависимостями.
